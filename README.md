# משחק התקציב 🛒

משחק מסיבות בעברית: בוחרים תוצר סופי (לאפה שווארמה, קבוצת כדורגל, פיצה, סטאפ גיימינג או כל נושא חופשי),
והפריטים שלו עולים למכירה אחד אחרי השני. השחקנים מתווכחים מי קונה ובכמה, והשופט מעדכן באפליקציה.

## איך משחקים
1. **הגדרות:** שמות השחקנים (2 ומעלה) והתקציב של כל אחד, בחירת תוצר או הקלדת נושא חופשי, ועריכת רשימת הפריטים.
2. **סיבובים:** בכל סיבוב מוצג פריט אחד בגדול. השופט בוחר מי לקח, מקליד כמה שילם ולוחץ "אשר ועבור לפריט הבא" (או Enter).
   אפשר לדלג אם אף אחד לא לקח, לחזור צעד אחורה, ולהוסיף פריט באמצע המשחק.
3. **סיום:** כל שחקן רואה מה הרכיב, כמה שילם על כל פריט, סה"כ הוצאות וכמה נשאר.

המשחק נשמר בדפדפן, כך שרענון הדף לא מוחק את המצב.

## הרצה
אין צורך בהתקנה. אפשר לפתוח את `index.html` בדפדפן, או להריץ שרת מקומי:

```bash
python3 -m http.server 8000
# ואז לפתוח http://localhost:8000
```

## פרסום ב-GitHub Pages
Settings → Pages → Source: **Deploy from a branch** → Branch: `main`, תיקייה `/ (root)` → Save.
אחרי דקה-שתיים האתר יהיה זמין בכתובת `https://<שם-המשתמש>.github.io/him/`.

## קבצים
- `index.html`: מבנה שלושת המסכים
- `style.css`: העיצוב (כולל מצב כהה ותצוגת טלפון)
- `items.js`: מאגר התוצרים והפריטים, ויצירת רשימה לנושא חופשי
- `app.js`: לוגיקת המשחק
